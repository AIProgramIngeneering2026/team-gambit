# D-26. Повтор запроса и воспроизводимость запуска

- **Статус:** принято.
- **Источник:** [issue #26](https://github.com/AIProgramIngeneering2026/team-gambit/issues/26), исправление замечаний review по поручению автора задачи.
- **Вопрос:** как вернуть прежний Job при конкурентном повторе у лимита и сохранить результат при смене версии движка?
- **Решение:** операции создания одного клиента сериализуются в короткой транзакции до поиска ключа и проверки лимита. Job сохраняет обе версии при создании, а `rerun` копирует их; недоступная версия движка даёт `engine_unavailable`, подмена запрещена. Окно сигнала без явного значения определяется как `max(252, required_bars)`.
- **Варианты:** только уникальный индекс не закрывает отказ по лимиту до вставки; запуск текущей версией движка потребовал бы ослабить гарантию воспроизводимости. Выбраны сериализация и закрепление версий.
