# TradeLab — бэктестер торговых стратегий

TradeLab проверяет торговую стратегию на исторических рыночных данных и по результатам проверки формирует текущий сигнал стратегии (`signal`) на основе последних доступных рыночных данных.
## Проблема

Частный инвестор, который хочет торговать по формальным правилам, вынужден либо торговать «на глаз», либо сам писать код для проверки идеи, либо доверять чужим «сигналам» без возможности проверить их на истории. Ручная проверка стратегий почти всегда страдает от подглядывания в будущее, игнорирования комиссий и невоспроизводимости результата.

## Для кого

- активные частные инвесторы, торгующие по правилам;
- начинающие алготрейдеры, проверяющие первые стратегии;
- аналитики и студенты, изучающие поведение стратегий на реальных данных.

## Что входит в систему

- Каталог встроенных стратегий (SMA crossover, RSI mean reversion, breakout, buy & hold) с настраиваемыми параметрами.
- Запуск бэктеста как задания с жизненным циклом (`created → queued → running → completed / failed / canceled`) и идемпотентным созданием.
- Исторические данные Московской биржи через адаптер внешнего поставщика, кеширование снимков данных.
- Метрики результата: доходность, максимальная просадка, Шарп, список сделок, кривая капитала, сравнение с «купить и держать».
- Текущий сигнал стратегии (`signal`: `BUY` / `HOLD` / `SELL` / `INSUFFICIENT_DATA`) с обоснованием и временем последнего бара. 
- Сравнение нескольких стратегий на одном инструменте и история запусков.
- HTTP API с машиночитаемым контрактом (OpenAPI).

## Что точно не входит

- Реальная торговля и подключение к брокеру — сервис только исследует стратегии.
- Внутридневные и тиковые данные, высокочастотная торговля.
- ML-стратегии и автоматическая подгонка параметров под историю.
- Портфельный учёт и расчёт налогов.
- Индивидуальные инвестиционные рекомендации: TradeLab формирует только сигнал конкретной стратегии (signal) на основе последних доступных рыночных данных. Сигнал отражает результат работы алгоритма и не является советом к совершению сделки.
